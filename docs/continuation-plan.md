## 追加阶段：WGSL 单一源码

已本地完成光学/顶点和共享 blur/blit 的 WGSL→GLSL ES 300、反射 uniform ABI、固定 packer 与生成漂移检查。19 测试、84 像素案例、12 组性能、DPR 2 四实例清理、消费20组矩阵与生产 WebGL 交互通过。普通消费构建无需 Rust。详见 [报告与复跑](wgsl-single-source.md)，所有发布仍等待授权。高级光学模型与 DOM 采集继续作为独立后续工作。

## 追加阶段：光学试验与 TS 准备

Chrome/Chromium 下完成冻结 WGSL 基线对照；其他浏览器兼容由用户明确延后到 WebView 支持阶段。本轮没有新增兼容层。全解析梯度超像素阈值，混合梯度收益不稳定，高度场视觉及参数语义不同，三者保留实验；有界高光五次幂与部分设置原子校验保留。最终 25 个 Node 契约、84 个精确 RGBA 对照、12 组资源性能、10 个 Chrome 后端/主题 smoke、20 个真实消费案例及生产连接/拖动/主题通过。GPU timestamp 已有单 pass 样本，尚无稳定加速结论；驱动显存未测。四实例 DPR2、18,000前台帧限定运行、周期resize/blur、场景失败恢复和零资源最终清理通过，见 [光学报告](optical-refinement.md)。

最终 JS/声明/生成工具/测试/构建配置已归档作为迁移前检查点；后续按 [TS 入口](ts-migration-plan.md) 先迁移纯函数与配置，再迁移来源/renderer/controller/React，保持公开接口与像素行为。运行时代码尚未迁移，不推送、不部署、不发布 npm。其他浏览器、WebView、原生 DOM 与生产长期运行是后续独立验收，不因开始 TS 自动变为已支持。
